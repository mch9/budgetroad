표를 보는 게 좋을지를 1번 분석 하고 제안을 해 줄래 아니면은 내가 아래에다가 우리 팀이 볼려고 하는집 표들을 내가
붙여 줄까 일단 내가 아래 붙여 줄테니까 너가 보면서 이 표를 뽑으려면은 뭐 어떤 이벤트를 심으면 될지 어떤
속성들이 필요 할지를 1번 분석 하고 판단해서 계획을 세워줘 예를들면은 결과 페이지의 각태 배 어떤 체류시간이 나 각
탭 배 스크롤률 스크롤로 어떤 영역까지 확인을 하는지에 대한 영역 확인률 결과 페이지에 탭 별로 이런 것들도 보고
싶고 그런 거 종합 했을 때 저 장 이나 공유 하기를 누른 특징은 어떤 결과 폐에의 체류시간이 되더라 본 어떤 페이지의
영향을 100% 다 확인 했더라 혹은 폭우을 몇 번 눌러 봤더라. 역은 항목 별 내역 에 드롭 다운을 눌러 보거나 항목
별내역 에서 다시 추가금케어의 턱 구를 눌러 봤다가 다시 항목별 내역이 들어가서 다시 1번 더 확인 했더라. 추가금
이동 된 거를 이런 식으로자작 율이나 공휴일이 낮게 나았다 라고 한다면은 왜 낫게 닿았는지를 우리가 학습 하고 성장
할 수 있는 구조까지 다 만들어야 될 거 같애 일단 아래에다가 우리팀이 벌려고 했던 지표들을 다 넣어 볼테니까 어떤
이벤트들 와 석상들이 필요한지 혹은 더 추가 될 추가가 되어야 하는 이벤트들은 집 표들은 무엇인지 1번전체적으로
